Realtime Conveyancer - redesigned UI (clickable prototype)

Open index.html in any modern browser (Chrome, Edge, Firefox, Safari).
No server or install needed; it also works when hosted on any static web host.

Pages
  index.html    Dashboard
  matter.html   Matter 00003 overview
  overdue.html  Overdue settlements list

Tips
  - Ctrl+K (Cmd+K on Mac) or / opens global search.
  - Click chart bars, calendar days, accordions, checkboxes and buttons - most are interactive.
  - Fonts load from Google Fonts when online; offline, a system font is used.
  - All data is sample data for demonstration.
